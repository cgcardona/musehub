How the scan works

  1. Takes the repo's last 20 merged pull requests and finds the functions and classes each one changed.
  2. Without Muse: for each changed name, counts what an agent reads to find its callers two levels deep: search output, then every matching file it opens (up to 25 per name).
  3. With Muse: counts the size of one muse code impact --json answer listing the same callers.
  4. Tokens are estimated at four characters each. The per-task figure applies the measured share of agent tokens spent reading and searching, 46.5% (Zhang et al. 2026, arXiv 2606.14066), and assumes Muse replaces at most 85% of it.

This is a simulation from the code, not an agent run. To measure it on your own agent, paste this prompt into it, in your repo:

{{ scan_prompt }}
